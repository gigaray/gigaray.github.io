The survey frame is registered into Nav2’s map frame by boot alignment with a live-measured standoff (TF lookup through the URDF mount chain), so a Nav2 rover (Jetson, ZED2i, LiDAR, RoboClaw) drives to surveyed markers without seeing a tag live; completed a full autonomous run on a lab layout (Oct 2026).   • ReFIT — Reservoir Computing on FPGA & ML Numerical Forensics: Goal: replace an RNN’s dense hidden layer with a reservoir—an Echo State Network (ESN, ridge readout)—on UCI Human Activity Recognition (HAR) IMU data, and compare CPU/GPU results against a Vitis HLS implementation on an AMD Kria KR260 FPGA (in progress, with golden-vector verification planned).

Engineering Method — Human-Gated Agentic Development

  • Written charter: AI coding agents (Claude Code) work under a 26-rule written engineering charter—ask, don’t assume; one design decision at a time; no code until every open question is answered; commit/push only on explicit approval; strict separation of personal and organization repositories.
  • Design before code: Decisions are settled and recorded before implementation—e.g., survey→map registration designed as three interchangeable providers with a written design document before the default was built; the ESN reservoir designed decision by decision against FPGA (Vitis HLS) constraints before any code.
  • Human hands on hardware; verify before claim: The agent never touches the robot or runs training directly—I execute every hardware and training run and feed back raw output. A fix counts only when confirmed on hardware (NFC image-tiling fix across four test images; LZO decoder validated against vendor streams).
  • Bit-level evidence over narrative: Tensor hash fingerprints, float64 reference runs, and ULP-level diffs (ReFIT); byte-identical cross-platform test vectors (Odetara); golden-vector verification planned for the FPGA path. Over-claims are explicitly walked back when the evidence does not yet support them.
  • Continuity across sessions: Git-versioned per-project worklog with a stand-alone hand-off prompt per stream, verbatim evidence logs, repo-level CLAUDE.md onboarding, and session links in commit messages—sustaining parallel work across NFC, PQC, ROS2, UAV, and FPGA streams.
